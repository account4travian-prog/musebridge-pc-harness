MB-32 stores private per-project bare Git repositories under the application data directory. Exact-byte fast-import blobs bypass project Git filters, hooks and attributes and never use the project's index or HEAD. Start/end trees are linked to the owning conversation/run/root. Cold file reads use a bounded pool of four I/O threads and batches of eight. Unchanged metadata reuses private blobs/trees; restoration independently compares actual current bytes against the fixed run-end tree.

Additional contained fault tests inject an I/O failure during the second restore publication, verify the allowed partial state, and complete a deliberate idempotent manual retry from retained evidence. A real temporary junction cannot enter snapshot/restore scope and its synthetic neighbor remains unchanged. These are fixture I/O/restore tests, not power-loss or production-destructive testing.

Restore covers files only. It cannot undo installs, network calls, deleted databases, excluded files or effects outside the project. Unknown/interrupted runs and runs ending with active shell jobs do not get a falsely certified end snapshot. Multi-file restore preflights first but is not a cross-file transaction; a mid-restore failure remains inspectable and is never blindly replayed. Concurrent external edits still have the ordinary filesystem compare/publication race; the harness is not an OS sandbox.

Parallel integration acquires a canonical-root writer lease before project writes and configured hook commands, and rebases the snapshot on the first write after a prior chat releases ownership. The successive-writer restore fixture verifies that restoring the later chat retains the earlier chat's completed bytes. Snapshot differences can include unrelated external edits during the observed interval; review them rather than treating them as authenticated attribution. Metadata caching is not forensic change detection: a same-metadata rewrite can evade cached snapshot discovery. Restore independently reads actual current bytes before publication; excluded or undiscovered changes cannot be certified by finish-line feedback.
